# Kapitik Art Studio — React/Vite

Customer-facing website prototype for Kapitik Art Studio.

## Stack

- React
- Vite
- React Router
- CSS design system
- Vercel-ready SPA

## Brand palette

The interface uses the Kapitik green sampled from the current website as the primary brand color, supported by the warm gold visible in the supplied Kapitik logo.

- Forest Green: `#214721`
- Deep Green: `#163A19`
- Dark Green: `#102F14`
- Warm Gold: `#E0AE4F`
- Gold Cream: `#F7EDC9`
- Pale Green: `#F4F6F1`
- Soft Green: `#E9F0E7`
- Ink: `#162119`
- Slate: `#667267`

Green is the primary action and navigation color. Gold is deliberately reserved for small accents, active details, and the main navigation CTA so it supports rather than competes with the green identity.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Import the repository into Vercel. Vite should be detected automatically.
