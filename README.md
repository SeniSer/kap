# Kapitik Art Studio — React + Vite

Customer-facing prototype rebuilt from the previous V7.1 static version.

## Included
- React Router client-side routing
- Responsive shared header/footer
- Home, Bamboo, Acoustic, Calculator, Projects, Dealers and Contact pages
- React product catalogue with filtering and sorting
- Clickable catalogue cards with a real floating product-selection modal
- Modal → calculator handoff with model and indicative price preselected
- Multi-wall area calculator, openings, waste allowance and estimated material cost
- Quote form demo and WhatsApp shortcut
- Existing Amp-style design system preserved
- Vercel SPA rewrite configuration

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Deploy
Push to GitHub and import the repository into Vercel. Vercel will install dependencies and run the Vite build.

## Important
The 25,000–60,000 ₸/m² product prices are prototype/indicative values requested for the demo. Replace them with confirmed Kapitik commercial pricing before production.
